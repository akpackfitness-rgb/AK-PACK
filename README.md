# AK PACK FITNESS — Website

Official website for **AK Pack Fitness**, Kodungallur, Kerala.

## 📁 Project Structure

```
akpack/
├── index.html          ← Main webpage
├── css/
│   └── style.css       ← All styles (red & black theme)
├── js/
│   └── main.js         ← All JavaScript (quotes, tips, chart, cursor, reviews)
├── images/
│   └── logo.png        ← ⚠️ ADD YOUR LOGO HERE (PNG, transparent background)
└── README.md
```

## 🖼️ Adding Your Logo

1. Name your logo file exactly: `logo.png`
2. Place it inside the `images/` folder
3. Recommended: PNG with transparent background, min 300px wide
4. If no logo is found, the site will show **AK PACK FITNESS** as styled text automatically

## 🚀 Uploading to GitHub Pages (Free Hosting)

### Step 1 — Create a GitHub account
Go to [github.com](https://github.com) and sign up (free).

### Step 2 — Create a new repository
- Click the **+** icon → **New repository**
- Name it: `akpackfitness` (or any name)
- Set it to **Public**
- Click **Create repository**

### Step 3 — Upload files
- Click **Upload files**
- Drag and drop the entire project folder contents:
  - `index.html`
  - `css/` folder
  - `js/` folder
  - `images/` folder (with your logo.png inside)
- Click **Commit changes**

### Step 4 — Enable GitHub Pages
- Go to repository **Settings**
- Click **Pages** in the left sidebar
- Under **Source**, select `main` branch → `/ (root)`
- Click **Save**
- Your website will be live at:
  `https://YOUR-USERNAME.github.io/akpackfitness`
